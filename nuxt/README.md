CeliBlog - Nuxt frontend

This folder contains a minimal Nuxt 3 scaffold for the CeliBlog frontend.

Quick start (from this folder):

1. Install dependencies

   npm install

2. Run dev server (PowerShell):

   npm run dev

This is a lightweight placeholder. Next steps:
- Wire API base URL to your backend (e.g., using runtime config)
- Add pages, components and styling
